## Что показали проверки

- CSV 008b, 014a, 015a, 019b и 020a содержат ровно id,y_pred, по 8 000 уникальных ID Test, конечные неотрицательные значения. **У 008b порядок строк отличается от Test.** Все сравнения выполнены по ID. У 020a минимум 260,314, максимум 2 018 646,055.
- Общий объём каждого из пяти CSV равен 2 219 915 137,27. Суммы совпадают по каждому горизонту при rtol=10⁻¹². Восемь значений перечислены в отчёте. Среднее |Δ прогноза| для 015a → 019b составляет 5 811,743, для 019b → 020a составляет 2 228,264. Это расстояния между прогнозами.
- У архивной сети лучший pooled Score 0,329024891 (smoothed, α=1) дал выигрыш на одном из трёх фолдов. Выбранная per_step, α=0,8 дала 0,330259487 и два выигрыша. Оба числа относятся к валидации над 006a.
- При обучении TCN и адаптера group_prediction получает сумму фактических меток группы. На Test доступен прогноз суммы. В tcn_training.json все 34 validation_group_wape равны null, последняя train_group_wape равна 0,320669. Исторический replay готовой полной TCN или адаптера занизил бы ошибку. Коэффициенты 020a не подбирались.
- На финальном префиксе ни у одного маршрута средний target за 336 слотов не опускается ниже 100. Порог масштаба там не действует. В полном target 69 841 ноль и 69 889 значений ≤50; признаки CatBoost с именем zeros учитывают ещё 48 малых положительных значений. Отсечение готового 020a снизу в нуле ничего не меняет. Влияние отсечения сырых выходов CatBoost и его признаков на WAPE 020a отдельно не установлено.
- В halfhour_causal интервал для неизвестного начального получаса сжимается по истории маршрута. На финальной отсечке у **всех 1 000 маршрутов** нижняя граница выше верхней на 7…75 единиц, медиана 26. На фолдах 3–5 также по 1 000 перевёрнутых интервалов. Возвращаемая ширина max(upper−lower,0) равна нулю даже при противоречии ограничений. Точное физическое восстановление из всей истории этим уравнением не подтверждается. Midpoint и приведение результата маршрута к float32 повторяют старую реализацию. Получаем q0=139 803 192,5; на уровне сети рекурсия со всеми восемью суммами 020a и 021a остаётся строго положительной. Маршрутные прогнозы представляют часовой target, а не наблюдения фактических получасов.
- В признаках CatBoost индекс t+h−lag для сезонных значений использует lag≥48 и h≤8. Новый сезонный прогноз тоже использует только прошлые слоты. Тест для всех трёх моделей меняет все значения после origin; прогноз идентичен. Отдельно проверена последняя строка обучающих меток Ridge.
