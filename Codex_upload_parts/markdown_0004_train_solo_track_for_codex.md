# RWB — полный набор train_solo_track.parquet: инструкция для Codex

## Что приложено

- `train_solo_track_full.csv.gz` — **полный** экспорт оригинального Parquet в CSV, сжатый gzip. В нём сохранены **все 4 630 000 строк** и исходные 9 столбцов, без сэмплирования, агрегации или изменения числовых значений. `timestamp` записан как читаемая дата и время.
- `train_solo_track_preview_400.csv` — 400 настоящих строк, равномерно выбранных по порядку строк внутри каждой из пяти групп Parquet; **не** заменяет полный набор данных.
- `train_solo_track_metadata.json` — проверенные размеры, периоды и статистика.
- `train_solo_track_for_codex.md` — этот документ.

## Схема и смысл полей

| Поле | Тип в экспорте | Описание по организаторам |
|---|---|---|
| `route_id` | целое число | Анонимный идентификатор маршрута |
| `timestamp` | дата-время `YYYY-MM-DD HH:MM:SS` | Временная точка наблюдения |
| `status_1`, `status_2`, `status_3` | целые числа | Количества товарных идентификаторов, прошедших соответствующие этапы обработки на текущем складе за предыдущие 30 минут |
| `status_4`, `status_5`, `status_6` | целые числа | Количества товарных идентификаторов, прошедших соответствующие этапы на предыдущем складе за предыдущие 30 минут и направляющихся на текущий склад |
| `target_1h` | целое число | Количество товарных идентификаторов, отгруженных по маршруту за последний час |

От экспертов: подробной расшифровки каждого статуса нет; один товар может появляться в разных статусах/строках. **Нельзя считать статусы непересекающимися группами товаров без проверки.** Отдельные часово-целевые окна могут перекрываться, поэтому суммы соседних значений `target_1h` не следует автоматически считать независимыми получасовыми отгрузками.

## Как Codex должен читать полный экспорт

В проектной директории с архивом CSV или после копирования в `data/raw`:

```python
import pandas as pd

path = "train_solo_track_full.csv.gz"
# gzip распаковывается pandas автоматически
train = pd.read_csv(path, parse_dates=["timestamp"])
print(train.shape)
print(train.dtypes)
print(train.head(10).to_string(index=False))

# Рекомендуется перед временным моделированием
train = train.sort_values(["route_id", "timestamp"]).reset_index(drop=True)
```

**Примечание:** полный CSV может занимать много оперативной памяти. При ограничении RAM читайте по частям:

## Контекст задачи RWB

- Прогнозируются **8 будущих точек** с шагом **30 минут** по каждому маршруту (4 часа).
- `test_solo_track.parquet` не содержит целевых значений и статусов.
- Используйте только разрешённые данные соревнования; внешние открытые датасеты запрещены.
- Официальная метрика: `WAPE + abs(RelativeBias)`, где `WAPE = sum(abs(pred - true)) / sum(true)` и `RelativeBias = sum(pred) / sum(true) - 1`.
- Не допускайте временной утечки при формировании обучающих и валидационных выборок. Чтобы обученная модель могла предсказать Test, её признаки должны быть доступны на момент прогноза.
- Формат отправки: CSV с колонками `id` и `y_pred` в соответствии с Test.
