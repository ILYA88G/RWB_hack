# Историческая сборка полного рецепта 021a

Отсечка прогнозирования — суббота 25.10.2025 10:30, за неделю до конкурсной. Оцениваются 1 000 маршрутов × 8 горизонтов с 11:00 до 14:30. Сравнения зафиксированы до получения метрик: исходный 021a, поправка первого горизонта exp_025 с весом 20%, поправка сети exp_026 и их сочетание. Также сохраняются промежуточные матрицы 008b, 014a, 015a, 019b, 020a. Это ретроспективный фолд на ранее изучавшейся субботе с фиксированным рецептом. Все обучаемые компоненты строятся заново, признаки и метки читаются из parquet по верхней границе даты. Рецепт и гиперпараметры были выбраны позднее самой исторической даты.

## Зависимости и отсечки

- 005a и 006a. Исходные функции подготовки признаков и обучения, восемь моделей на компонент, 14-дневное окно, последний допустимый источник за четыре часа до отсечки. Для сетевой базы берутся 50% прогнозов 005a и 50% 006a. У LightGBM ограничены четыре потока.
- 008b. Штатная сеть LightGBM28, калибровка отдельно на каждый горизонт с весом 0,8 и пределом 5%.
- 014a. В корне проекта восстановлен исходный `train_model_014a.py` из коммита `430e61f`. Идентификатор исходного blob — `e9911ab66589f6511bfde5b107542fee4de467c0`. История включает последние 37 дней с обеими границами. Используется равная смесь нормированных Ridge и LightGBM.
- 015a. На том же 37-дневном префиксе переобучается CatBoost из train_model_015a.py. Его распределение получает 50%, другая половина приходит из 014a.
- 019b. Длинный CatBoost учится до четверга 23.10 10:30 включительно, с двухдневным отступом до субботнего origin как в оригинале. Использован исходный блок выборки и обучения, 400 000 + 400 000 строк, 1 400 деревьев. Для прогноза признаки доступны по 25.10 10:30. TCN учится 34 эпохи исключительно на префиксе с 28.07 по 25.10 10:30. В обучающих группах известны их исторические метки. Инференс распределяет прогнозные сетевые бюджеты 008b. Маршрутная смесь — 25% 015a, 25% длинного CatBoost, 50% TCN.
- 020a. Заморожена переобученная TCN. На том же префиксе строятся восьмиэпоховый адаптер и штатная локальная поправка robust Ridge. К 019b прибавляются 0,5 × разность адаптированного и исходного TCN и 0,0625 × разность локального и глобального Ridge.
- 021a. На сетевом префиксе применяется утверждённое правило exp_021/rule.json. Суммы восьми горизонтов проверяются по отдельности.
- Метки. Только после записи predictions.npz оценщик читает отдельный диапазон 25.10 11:00–14:30, выравнивает факты по route_id и timestamp и считает метрики заново из записанного архива. Общие Score посчитаны на всех 8 000 строках. Квартили определены по последним 336 доступным значениям каждого маршрута.

## Воспроизведение

Рабочий runtime — Windows x64, CPython 3.13.1, torch 2.15.0+cpu, catboost 1.2.10, lightgbm 4.7.0, numpy 2.5.4, pandas 3.1.1, scikit-learn 1.9.1. В exp_027/.venv установлен CPU PyTorch и подключены библиотеки окружений exp_024/exp_021. Для чистого окружения установить exp_021/requirements.txt, catboost==1.2.10 и указанную CPU-версию torch. Из корня репозитория выполнить:

```powershell
$env:OPENBLAS_NUM_THREADS = '2'
foreach ($stage in 'network','short','long','tcn','evaluate') {
    .\exp_027\.venv\Scripts\python.exe -B -u exp_027/replay.py $stage
    if ($LASTEXITCODE -ne 0) { throw "Failed stage $stage" }
}
```

Первые четыре стадии независимы. Каждая сохраняет свою матрицу или компоненты атомарно. Для повторной оценки нужны эти четыре NPZ. Прогнозы будущих экспериментов можно сравнивать непосредственно с готовой матрицей 021a из predictions.npz.

Отдельные проверки на конкурсной дате запускаются командами `exp_027/.venv/Scripts/python.exe -B exp_027/evaluate.py --upstream` и `exp_027/.venv/Scripts/python.exe -B exp_027/evaluate.py`. Первая восстанавливает 008b и 014a, затем 015a с архивным коротким CatBoost. Вторая берёт архивный 015a, длинный CatBoost, TCN и адаптер, пересчитывает 019b → 020a → 021a и сверяет каждую строку с фактическими submission по ID. Эти проверки не требуют фактов скрытого Test и не передают никаких данных в исторический фолд.
